# WayKeep

> **Record your routes. Keep your journeys.**

WayKeep is a mobile application designed to help users **record, save, navigate, share, and remember the routes they travel**.

Whether it's a shortcut a friend showed you, a daily route, a bike ride, or an entire road trip, WayKeep lets you preserve the journey and revisit it whenever you want.

## 🚀 Vision

WayKeep aims to become a personal **route and journey memory** platform.

The core idea is simple:

**Travel → Record → Save → Revisit**

Over time, WayKeep will go beyond route navigation and allow users to preserve complete journeys with photographs, places, activities, descriptions, and personal memories.

## ✨ Planned Features

### Route Management

* Record routes using GPS
* View routes on an interactive map
* Save and organize routes
* Add names, categories, and notes
* Search and manage saved routes
* Mark favorite routes

### Navigation

* Navigate using previously recorded routes
* Track progress along a saved route
* Detect when the user moves away from the saved route

### Sharing

* Share saved routes with others
* Import shared routes
* Export routes using standard formats

### Journey Memory

* Add photos to locations along a journey
* Mark places visited
* Record activities and experiences
* Add descriptions and personal notes
* Revisit an entire journey chronologically
* Replay a journey on the map

> Journey Memory will be developed after the core route-recording and navigation system is established.

## 🛠️ Planned Technology Stack

* **Flutter / Dart** — Mobile application
* **Google Maps SDK** — Maps and route visualization
* **GPS / Location Services** — Real-time location tracking
* **FastAPI** — Backend API
* **PostgreSQL + PostGIS** — Route and geographic data
* **Firebase Authentication** — User authentication
* **Git / GitHub** — Version control

Users will have control over which routes and journey information they choose to share.
